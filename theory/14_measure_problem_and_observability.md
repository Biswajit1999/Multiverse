# The measure problem, observability, and what a multiverse calculation can mean

If eternal inflation produces unbounded spacetime volume, naive event counts diverge. Ratios of infinities depend on how the spacetime is regulated. This is the **measure problem**.

A claim such as "vacuum A is more probable than vacuum B" is incomplete unless it specifies the landscape or transition network, the initial or boundary state, the measure or regulator, the observer/selection prescription, which events are counted, and the cutoff-removal procedure.

Different measures can produce different answers. This is a major unresolved theoretical issue and prevents this repository from assigning a unique probability that we should live in one pocket universe rather than another.

## Observable consequences

Multiverse models can still generate testable **model-specific** signals. Examples proposed in the literature include CMB temperature/polarization signatures from bubble collisions, spatial curvature in open-FLRW bubble interiors, modified primordial spectra caused by pre-inflationary dynamics, gravitational-wave backgrounds from phase transitions, and correlations tied to a particular landscape transition.

Searches for a signal constrain the corresponding model and parameter region. A null result does not falsify every theory ever called a multiverse.

The repository therefore separates three questions:

- **mathematical existence:** do the equations admit the solution?
- **dynamical plausibility:** is it produced from a specified state with non-negligible semiclassical weight?
- **empirical support:** does it predict a signal that data prefer over competing models?
