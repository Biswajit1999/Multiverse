# Project Roadmap — Phase 0 to Phase 10

**Current status after the present upgrade: Phase 3 / 10.**

| Phase | Deliverable | Status |
|---|---|---|
| 0 | Research question and scientific boundaries | Complete |
| 1 | Repository structure, citations, reproducible Python package | Complete |
| 2 | FLRW and scalar-field inflation baseline solvers | Complete |
| 3 | Origin report, reheating/bounce models, scientific visualizations, testability framework | **Current** |
| 4 | Full horizon/conformal-time engine and inflation parameter sweeps | Next |
| 5 | Scalar/tensor perturbation solver and $(n_s,r)$ model maps | Planned |
| 6 | Coleman-De Luccia Euclidean bounce solver and bubble-nucleation experiments | Planned |
| 7 | Quantum-cosmology minisuperspace / Wheeler-DeWitt numerical experiments | Planned |
| 8 | Data-facing model comparison with public CMB likelihood products | Planned |
| 9 | Interactive research website, animations and reproducible figure gallery | Planned |
| 10 | Integrated research release: report, validated simulations, benchmark datasets and versioned results | Planned |

Phase 10 does **not** mean "the multiverse is solved." It means the repository has become a mature, reproducible investigation of competing origin models.
